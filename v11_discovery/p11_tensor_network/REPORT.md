## 一、 核心结论速览（对三条“野路子”的严格实证判决）

本实验针对用户提出的三条绕开“全局静态向量坐标 $2^{256}$ 墙”的新范式——**(1) 目标条件化局部膜 $\Phi_\theta(x \mid y^*)$、(2) 神经李雅普诺夫漏斗 $V_\theta$、(3) 张量网络压缩坐标膜（MPS/MPO 跨轮解纠缠）**——设计了完全无坍缩、零作弊、含完整 64 轮消息扩展与随机密码/随机预言机双对照的四阶段实验，得出以下硬核结论：

1. **Part 1（精确 $\chi=2$ MPO 与逐门 MPS-TEBD）：100% 验证进位可零误差压缩，且精确锁定 `ROTR` 为纠缠爆炸唯一元凶**
   - 在 `n = 4, 8, 16, 32` 位宽下，双寄存器可逆模加 MPO 键维严格等于 **$\chi = 2$**、`XOR` 键维严格等于 **$\chi = 1$**，逐比特失配数为 **`0`**，解析逆 $U^\dagger$ 往返重叠误差仅 `1.07e-6 ~ 5.36e-6`。
   - 逐门 MPS-TEBD 消融实验显示：关闭 `ROTR`（`rotr_zero`）时，`n=12` 连跑 6 轮 `ADD+XOR` 截断误差严格为 **`0.00000`**（`max_bond=1`, `norm=1.00001`）；一旦打开 `ROTR`，仅 1–2 轮即打满键维并触发剧烈截断坍缩（`n=12, chi=32, R=6` 累积截断误差 `143.87`，存活范数暴跌至 `0.0173`）。
2. **Part 2（真实 256-bit SHA-256 精确解流形纠缠谱，$m=16$ nonce 比特，$R=1..64$）：惊人发现——SHA-256 仅用 2–3 轮即撞满量子多体 Page-Curve 理论上限，且比随机旋转快一整轮！**
   - **`R=2` 处暴露 SHA-256 旋转常数的极致扩散设计**：在 `k=4` 前导零目标下，真实 SHA-256 `(2,13,22)/(6,11,25)` 的中切纠缠熵已飙升至 **`5.5384 bits`（有效 Schmidt 秩 `chi99=103.8`，`F(32)=0.7175`）**，是同构随机旋转对照（`2.8867 bits`, `chi99=17.25`, `F(32)=0.9985`）的近 **2 倍熵 / 6 倍秩**；在 `k=8` 下，真实 SHA-256 甚至在 **`R=2` 就直接触顶随机预言机 Page-Curve（`6.7293` vs `6.7112 bits`）**，而随机旋转对照仍停留在 `3.9446 bits`（`F(32)=1.0000`）！
   - **`R >= 3` 直至满轮 `R=64`**：真实 SHA-256 的解流形纠缠谱、有效秩 $\chi_{99}$ 与 MPS 截断保真度 $F(\chi)$ **全程 100% 锁死在随机预言机 Page-Curve 上限**（`k=4`: `~7.106 bits`, `chi99≈195.4`; `k=8`: `~6.72 bits`, `chi99≈128.6`），不存在任何异常低纠缠通道。
3. **Part 3（精确正交 $O(4)$ 神经解纠缠器 $U_\theta$：路线 1 + 路线 3 联合测试）：`R=2` 有效解纠缠，`R >= 3` 无论局部特化还是跨 midstate 泛化均全面失效**
   - 凭借严格正交 Cayley 门（`ortho_max_err <= 4e-7`），彻底杜绝了 P10 Part C 的编码器坍缩。
   - **`R=2` 确实有效**：目标条件化局部膜 $U_\theta(\cdot \mid y^*)$ 将真实 SHA-256 纠缠熵压低 **`-0.3436 bits`**（`chi99: 160 -> 129`, `F(32): 0.3851 -> 0.5133`）；跨 48 个 midstate 训练的统一解纠缠器在 24 个**未见 midstate** 上同样稳定压低 **`-0.3019 bits`**（`chi99: 156.25 -> 128.29`）。
   - **`R >= 3`（`R=3, 4, 5, 6, 8, 16`）全线撞墙**：哪怕把 42 个精确 $O(4)$ 门直接过拟合到**单颗已知目标的完整解波函数**（路线 1 + 路线 3 的理论上限测试），熵降仅 `-0.0485 ~ -0.0036 bits`，与纯随机预言机（`-0.0613 ~ -0.0128`）完全一致；跨 midstate 泛化收益严格为 **`+0.0003 ~ +0.0018 bits`（零泛化）**。
4. **Part 4（李雅普诺夫漏斗消融：路线 2 首尾黑盒 vs 中间态轨迹，含“反自欺欺人”陷阱识破）**
   - **首尾黑盒 $V_\theta(x, y^*)$**：在 `R=1` 达到 `100%`（`32x` 富集），但从 **`R >= 2` 起立即跌穿为纯随机“高尔夫球场”**（`1v4 = 0.4741 ~ 0.5200`，贪心单步翻转恢复率 `0.12x ~ 1.50x`）。
   - **中间态轨迹 $V_\theta(S_{\lfloor R/2 \rfloor}, y^*)$**：在 `R=1, 2, 3`（距终点 $\le 2$ 轮）时，贪心单比特翻转恢复率高达 **`99.2% ~ 100.0%`（`31.75x ~ 32.00x`）**；但从 **`R >= 4` 起，贪心恢复率立即跌回随机线（`0.62x ~ 1.50x`）**。
   - **关键防骗诊断**：在 `R = 4, 5, 6, 8` 上，`intermediate_traj` 的 `1v4` 排序准确率表面上高达 `0.969 -> 0.729`（`z = +42.5 .. +20.8`），但被我们内置的 `greedy_1bit_recover_rate`（仅在活跃字 `A_mid` 内翻转）当场证伪——因为固定 `IV` 和 `W_{1..15}=0` 使 256-bit 中间态落在 32-bit 可达子流形上，4-bit 随机翻转更容易破坏 `B..H` 字的合法可达约束，模型学到的是**“是否属于从 `IV` 出发的前向合法状态”**，而非指向目标 $y^*$ 的逆向梯度！

## 四、 对“三条野路子”的最终科学判决

1. **为什么张量网络（路线 3）的实测结论比之前所有向量空间实验都更具有决定性？**
   - P10 时代人们还可以怀疑：“是不是因为网络没学好 32-bit 加法，或者编码器坍缩了，才没看到 SHA-256 的隐藏捷径？”
   - P11 通过精确 $\chi=2$ MPO 和 $2^{16}$ 精确 SVD 彻底**排除了优化器与近似误差的借口**：我们直接看到了 SHA-256 解流形本身的精确量子多体纠缠谱。结果极其冷酷且优美——**SHA-256 的旋转常数 `(2,13,22)/(6,11,25)` 在第 2 轮就比随机密码多制造近 1 倍纠缠熵，到第 3 轮就完全热化至随机预言机 Page-Curve 理论极限，后面还有整整 61 轮余量。**
2. **三条路线的真实边界**：
   - **路线 3（MPS/MPO + 神经解纠缠）**：在 $R \le 2$ 轮内确实能以精确、可泛化的方式压缩解空间；但在 $R \ge 3$ 轮，受限于体积律纠缠壁垒，局部 $O(4)$ 神经解纠缠器无法将熵降拉开与随机预言机的任何差距。
   - **路线 1（目标条件化局部膜）**：即使给它“上帝视角”（直接对着单颗目标的完整精确解波函数过拟合 42 个正交门），$R \ge 3$ 仍无法撬动 Page-Curve 上限，证明瓶颈不在“全局 vs 局部”，而在单颗目标解集本身的布尔纠缠复杂度。
   - **路线 2（神经李雅普诺夫漏斗）**：端到端 $V_\theta(x, y^*)$ 止步于 1 轮；下沉到中间态轨迹 $V_\theta(S_{\text{mid}}, y^*)$ 后可将有效贪心下降推进至 3 轮（距目标 $\le 2$ 轮），但面对 4 轮及以上时，真实目标导向坡度依然归零。
